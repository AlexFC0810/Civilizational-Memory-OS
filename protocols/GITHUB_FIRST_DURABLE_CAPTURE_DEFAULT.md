# GitHub-First Durable Capture — Default for House of Wisdom & Truth & Peace
**2026-11-17 | Owner directive: save valuable discoveries to GitHub by default.**
**Scope:** Civilizational Memory OS + Truth & Peace Engine research, ethical frameworks, content, source links, prompts, creative learnings and execution handoffs. This does NOT indiscriminately ingest unrelated private conversations into a public repository.
**Authority:** Existing `protocols/CONVERSATION_TO_CANON_MECE_PROTOCOL.md`, `COLD_BRAIN_BOOT.md`, `AGENTS.md`, and T&P `Context/SOURCE_INTELLIGENCE_OS.md` + `CIVILIZATIONAL_MEMORY_PRODUCTION_CONTRACT.md`. It **enforces capture default** without overriding truth gates, publishing approvals, security, or the repo's claim schema.

## Default behavior: every substantial House of Wisdom / T&P session
1. **Harvest:** extract each durable founder insight, original question, source/media link, correction, promising hypothesis, counterexample, active historical claim, significant editorial choice, research prompt and next execution step.
2. **Look up before write:** search current accepted files, open PRs, issues, source records and state capsule. Append or crosslink the canonical owning artifact rather than duplicating or creating a new OS. No arbitrary issue proliferation.
3. **Separate six truth types:** (a) founder's personal observation/recollection, (b) original moral opinion/proposed doctrine, (c) primary document or other recorded source, (d) scholarly inference, (e) empirical outcome, (f) content idea. The same sentence may mention several types; split claims into atomic records if needed.
4. **Choose owner:** raw incoming speech, screenshot, media asset, platform dynamics, hooks and production drafts → **T&P**; source-graded historical propositions, original-language research, scholarly debate, historical comparisons, corrections and epistemic status → **CMOS**. Only a lightweight link/claim handoff crosses the boundary. Public website pages consume CMOS; they are not claim authority.
5. **Provenance required:** who said it, where it came from, exact date and/or timestamp, literal URL, direct quotation scope if relevant, primary vs secondary source, rights/ownership where relevant, caveat and best contrary evidence. When a provided clip/video couldn't be accessed, label it `user-described/unverified`, not reviewed.
6. **Capture material that might be wrong:** preserve the interesting proposition as a *hypothesis*, the strongest countercase and a falsifier. Never make user enthusiasm an accepted historical verdict. True historical canon remains source-closed; draft material stays on draft branches.
7. **Commit immediately when authorized tools work:** create/update exact files on the active authorized branch, comment/link existing issues, and return **real GitHub URLs**. Keep PR review boundaries and don't merge source-uncleared work into main or publish outward without separate authorization.
8. **Leave a resume needle:** update the single `prompt-library/EPIPHANY_STATE_RECOVERY_AND_COMPOUNDING_SESSION.md` capsule when a consequential discovery changes the frontier (not every stray thought); append the best next original source or counterexample to find.
9. **Close with a receipt:** new/revised paths; commit/PR/issue links; explicitly state what is verified, provisional, speculative, staged, rendered, or publicly approved. If GitHub unavailable, state the exact failure and give a portable copy-ready handoff—**never claim saved when not saved**.
10. **When no material change, avoid noise.** Don't commit filler or a second summary that merely repeats the source. The promise is **zero-loss durable insights**, not maximal file count.

## Privacy / safety / integrity
- **CMOS may be public.** Do not send private user health, financial information, third-party personal data, credentials, proprietary client materials, user-uploaded photos or full sensitive chat transcripts to a public repository without separate permission. Preserve non-sensitive, generalizable insights and link to restricted T&P where appropriate.
- Follow image/media rights; screenshot analysis doesn't grant permission to redistribute it.
- No diagnostic/dehumanizing label about public figures presented as fact; cite exact conduct and scope.
- Do not copy unlicensed long source texts or upload videos/photos without rights.
- A saved prompt is not an autonomous monitor; future chats must connect to GitHub and invoke the live workflow for edits. GitHub comments and drafts are not deployed apps.
- Human per-item approval before public content remains mandatory.

## Current historical examples from this conversation
- **Ashoka is not dismissed.** India has serious evidence of early inscriptions and long-lived plural animal welfare traditions. Compare geographical reach, compliance, longevity, changed institutions and welfare effects, not the rhetorical “first.”
- **Important corrective:** Ashoka's Rock Edict II states treatment for people/animals; this does **not** establish a network of hospitals. Dominik Wujastyk, “The Evidence for Hospitals in Early India” (2022), DOI 10.18732/hssa70.
- **Ottoman livestock regulation:** dated work-animal legal codes, 1765 and 1810 Istanbul animal-use regulations documented by Necmettin Kızılkaya (2020); enactment isn't itself evidence of effective population-wide compliance.
- **India over centuries:** Hindu gaushalas and Jain panjarapoles described by travelers c. 14th–17th centuries and later institutional history; do not falsely imply they were a single unbroken program of Ashoka's government.
- **Modern welfare:** halal law and animal mercy norms must be compared with sheep-specific handling/stunning evidence and whole-life welfare, not assumed superior by religious label.
- **Visual work:** no new dashboard framework; one offline, self-contained HTML historical clarity map belongs with T&P creator output, linking back to CMOS source documents and PRs.
